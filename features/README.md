# Plans — Klotilda

Forward-looking designs, refactor plans and reviews, one directory per feature:
`features/<YYYY-MM-DD>-<slug>/README.md`, headed by `**Ticket:**` and `**Status:**`. A plan never moves; its
status changes in the file. Klotilda has no ticket tracker, so a plan carries `**Ticket:** none yet`.

`./features.sh` (repository root) lists the plans with their statuses and checks the links; `./features.sh new
<slug>` scaffolds one. The layout, the status vocabulary, reviews and epics are described in the
`feature-plans` skill (`.claude/skills/feature-plans/SKILL.md`).
